# 知解冒险岛 V5 · 荒野与工坊

这里只公开打包后的试玩网页和引擎许可，完整应用源码仍在私有仓库。iPhone 使用 Safari，建议横屏。

选择“进入遗迹试炼”，体验采集、工作台、木/石/铁镐斧剑、真实耐久、小熔炉、铜铁熔炼、木炭、玻璃、昼夜循环与床。用普通材料自由建房，潜行保护搭建边沿。保留修桥、洞穴机关、伙伴救援、战斗与灯塔任务。原营地和遗迹分别保存，旧建筑及物资会保留。

点击“合成”打开工具与设施配方；工坊设施建在登陆点，金属矿需要石镐。每类携带一把工具，高级制作会替换旧工具。熔炉加入材料/燃料后返回探索，按有效游戏时间烧制；暂停与离线不推进。设置中可调画质、辅助跳跃、音效和灵敏度。

这是有限地图的独立玩法试玩，尚无无限世界、多人、红石或云存档。学习对接按用户要求最后加入；不产生学习币/成长，不授予正式区域权限。保存仅在当前浏览器，清除网站数据会丢失本机进度。
