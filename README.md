此仓库只公开打包后的试玩网页和引擎许可，完整应用源码仍保存在私有仓库。

V4 改进跳跃：快速点按缓存、提前按容错、按住连续跳、默认辅助上台阶与更大的按钮。暂停菜单可调整辅助、灵敏度、音效、镜头摆动与画质。
