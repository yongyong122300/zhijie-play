# 知解冒险岛 V8 · 自动化与下界

新增箱子、漏斗、观察者、黏性活塞和可往返下界。工坊的“红石”可制作自动化器件，“下界”提供完整材料与建门步骤。箱子27槽、漏斗5槽，对准点互动存取；漏斗从上吸入、向出口送出，通电锁定。观察者观察眼睛前的一格，从背面红点输出脉冲；黏性活塞缩回时拉回前面一格。箱子、漏斗和熔炉内部物资随活塞搬动并保存。

铁镐采钻石，钻石镐采黑曜石；砂砾取得燧石，铁锭+燧石制作打火石。搭竖直4×5黑曜石框、内部空出2×3，四角可省。对准框底上表面点“点燃门框”，走进紫色门体停留4秒。进入下界后先走出门体，再进入可返回。下界入口附近可采石英与萤石，带回制作观察者和红石灯。湿地小史莱姆有机会掉黏液球，可制作黏性活塞。

下界有洞穴、菌林、灵魂沙、岩浆块和熔岩。床会爆炸；熔岩造成持续伤害。两界建筑、容器和掉落独立保留，死亡后随身物品留在死亡维度。旧存档升级前保留原始恢复记录，旧建筑保留。手册明确暂停单人游戏，清除浏览器网站数据会丢失本机存档。
